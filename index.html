QAT and PECTA assessment flow

Moawin teachers pick a test type first. PECTA runs the flow they have today. QAT lets them browse to a ready-made Quality Assurance Test paper by grade and subject. Try it on the left, then hand the spec on the right to the bot.

Teacher programme

What changes

  • One new question, asked first, only for Moawin.When a Moawin teacher sends /assessment and taps start, the first screen asks which kind of test they want. Rawalpindi teachers never see it and go straight to Grade, as they do now.
  • PECTA keeps the current flow exactly.Grade, Subject, Chapters, where questions come from, how many and total marks, kinds of question, Ready, then a generated PDF. No edits to those screens.
  • QAT is a browse-and-make flow.Grade, Subject, Units, Ready. There are no question-count or question-type screens because every QAT paper has the same fixed shape. The bot writes a new paper in that shape and sends it as a PDF.
  • The curriculum does not change.QAT questions come from the same Punjab textbooks the bot already uses for PECTA. Only the shape of the paper is different. The next section gives that shape, so the bot needs no other file.
  • Same look as the existing flow.Same WhatsApp Flow shell, green progress bar, "New assessment" header, radio rows and Continue button.

How QAT questions are made

  • Same books, new format.QAT stands for Quality Assurance Test, the annual test PEF runs in its partner schools. It tests the same Punjab textbook content as everything else, so the bot loads nothing new. PEF's content book is week-by-week by learning outcome, and a QAT covers the month before the test. The teacher picks those units on the Units screen, and every question must be answerable from the chosen units only.
  • Every QAT paper has the same frame.25 marks, 30 minutes, three sections, each section banner showing its marks. The top box holds Roll No, Name, Gender tick, Time, Total Marks and Syllabus. Each question shows its marks as (marks per item × items = total), for example (1 × 13 = 13). Written questions get ruled lines or boxes. MCQs have four bubbled options A to D with one correct answer.
  • Language.Maths and English print each instruction and question in English with the Urdu line underneath. The Urdu paper is entirely in Urdu.
  • Fresh every time.Each request writes new questions on the same outcomes, so a teacher who asks again gets a different paper of the same shape.

What questions the bot makes from the content

  • One question tests one learning outcome.Every unit in the textbook lists what students should be able to do: identify, read, write, count, compare, arrange, decompose, solve. The bot takes the outcomes of the units the teacher chose and writes a question for each. All exercises and examples in those textbook units are fair material, and nothing outside them is asked.
  • The outcome's verb sets the kind of question."Arrange numbers in ascending and descending order" becomes an arrange-in-order question. "Identify the place value of a digit" becomes an underlined-digit question. The tables below map content to question for each subject.
  • Easy to harder across the paper.Section I recalls and recognises. Section II applies in short answers. Section III extends: a word problem, a paragraph, a letter.
  • Quality rules.Spread questions across the chosen units. Use the textbook's own words, number ranges and examples, never harder ones. Each MCQ has one clear answer and three believable wrong options. Every request writes fresh questions on the same outcomes. The answer key comes from the same outcome the question tests.

Build steps for the bot

  1. Add the Test type screen as the first screen of the /assessment Flow, shown only to Moawin teachers. Use whatever field the bot already uses to tell Moawin teachers apart.
  2. Route PECTA to the existing Grade screen with no other change.
  3. Add the QAT branch: Grade, Subject (only the subjects listed for that grade), Units (pick one or more units from the book's chapter list), Ready (with an optional answer key).
  4. Generate the paper from the blueprint for that grade and subject, using only the chosen units from the Punjab textbooks. Follow the frame and section rules exactly.
  5. Send the PDF named like QAT_Class4_Maths.pdf. If the answer key was ticked, add it as a second page set marked "Answer key".
  6. Log the choice (QAT or PECTA) on the assessment event.
  7. Test: a Moawin teacher sees the new screen and both paths work end to end for every grade and subject listed; a Rawalpindi teacher sees no change.
